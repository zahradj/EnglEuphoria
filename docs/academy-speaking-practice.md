## 2. The speaking ladder (every new language climbs it in the lesson)
shadow (say it together with the model) → repeat (alone after the model) → controlled (a given pattern, new words) → guided (a short exchange, first words of a frame) → free (own words). Supports fade up the ladder. Pronunciation is judged on being understood, not on accent (`academy-curriculum-teen-sla-and-l1-gaps.md`).

## 3. In the lesson
- Every game answer can be **said aloud**: the student says the word before or after tapping (blend → say the word; reader → read the line aloud; match → say it). The teacher confirms with one tap (a "Say it" check, to build in the player).
- Each lesson has the ladder as its spine: a shadow/repeat block after every vocabulary set, a controlled and a guided task in the middle, and the **Mission** (Take 1, feedback, Take 2) at the end; B1 and above add a free-speaking task.
- **Teacher talk ≤ 40 %**; after a question the teacher waits 4–5 seconds; correction is one thing done well plus one to try; shy students get private rehearsal and type-instead-of-speak (comfort first).
- **Speaking between lessons:** the Daily 10 includes a voice note (2–3 a week) and a "say it aloud" retrieval round, so speaking is practised daily, not only in the hour.
- **Assessment:** the Finale's Release is spoken; the six-strand checkpoint scores speaking with a rubric (accuracy, range, fluency, interaction, comprehensibility), not a single mark.

## 4. How the other skills feed speaking
| Skill | Feeds speaking by |
|---|---|
| Listening | the model to shadow; the exchange to answer; shadowing clips at every level |
| Vocabulary | the words in the Mission; chunks first so the student can talk early |
| Grammar | the rule stated plainly, then controlled sentences before free ones |
| Reading | read-aloud lines; a text to retell |
| Writing | plan a short text, then say it; the written Release is read aloud |
