## Beats
1. **HOOK** — Pip at the animal park: "Look! The animals can move. Let's copy them!"
2. **MODEL** — each animal says what it is and does ONE move with ONE body part.
3. **CHILD'S TURN** — Pip asks "Can you do it?" → 3 s pause (the child does the move) → Pip does it: "I can do it!"
4. **PAYOFF** — all four animals and Pip together: "From head to toe — we can do it!" → next page: the movement game.

## Note (build, 2026-10-06)
The animals have no voices of their own in the app (only the cast is voiced), so Pip says each animal's line
("Look! The tiger turns his head!") instead of the animal speaking. Same move, same picture, same order.
