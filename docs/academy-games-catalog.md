# Academy games & activities catalogue — 171 entries (+ 12 C1 additions, ids 172-183), one-to-one, ages 13–18, A1–B2

Companion to `docs/academy-lesson-system.md` (§5 says how to choose from this list per segment of the 60-minute Live Session). Owner rules that apply to every entry: no browser TTS (recorded voices only), no public leaderboards, comfort first, mechanics borrowed never content, Variety Rule (no more than 2 of the same kind in a row).

Scope: 60-min one-to-one online lessons, teacher + one student (13-18), shared interactive stage.
Legend. **Fmt**: D = digital-native (needs assets/shared canvas), C = conversation-only (no assets), D/C = works both ways. **Comfort**: Low = low-stakes, Med = medium, High = higher-pressure (use sparingly, opt-in, never first). Skills: V vocab, G grammar, R reading, L listening, S speaking, W writing, P pronunciation, Sp spelling.
Sourcing caveat: web search was NOT run in this session. Entries are built from established ESL/game-design knowledge of the named sources (TEFL Lemon, ESL Games Plus, British Council TeachingEnglish, Busy Teacher, ISLCollective, Wordwall/Kahoot templates, Cambly/Preply teacher practice, classic party/board/video games). Source column = inspiration, not a verified citation. Every source attribution is therefore [U] (uncorroborated this session) unless the game is a well-known classic whose origin is obvious. Mechanics only are borrowed, never content.

Universal 1:1 conversions: (a) teacher plays AGAINST student (teacher deliberately errs/loses sometimes), (b) student vs own best/clock, (c) teacher + student cooperate vs the game, (d) student "teaches"/judges the teacher, (e) student sets the rules/chooses the topic.

## Mechanics to avoid for 1:1 teen
- Public or named leaderboards, rankings, streak-shaming, and "you lost X points" screens.
- Elimination, "you're out", lives that end the session.
- Hard timers as the default (offer as opt-in; never on speaking).
- Forced on-camera acting (charades, mime, singing); always offer an audio/describe alternative.
- Teacher "winning" against the student repeatedly; forced guess-in-front-of-cameras gotchas.
- Unfinished error shaming (red crosses, buzzer sounds); use neutral "try again / nearly".
- Hangman with a hanged figure (use a balloon/house), and violent or gambling mechanics (loot boxes, gacha).
- Accusation-based social deduction aimed at real people; pressured cold-calling in debate with no prep time.
- Content that forces personal disclosure (family, money, body); allow aliases and "pass".
- Browser built-in TTS voices (project rule): use recorded voices only.

## 14. Added 2026-10-15 (B1 Season 1 lesson 1)

- **Hot Seat** (quiz-show ladder, 50:50 and Ask a friend; a wrong answer only greys a choice) — recall and activation.
- **Break the Clock** (boss fight: hit points, three shields, the round repeats with the reason) — choose between two tenses or forms.
- **Participle Wordle** (six tries, green / gold / grey, on-screen keyboard) — spell the past participle.
