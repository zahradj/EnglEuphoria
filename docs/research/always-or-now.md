# Always or Now? (Academy game) — design note

Owner request (2026-10-13): a present simple vs present continuous game, with some funny games.

## Method
1. **Cue words first.** Always, usually, every day, on Mondays = present simple (habit, fact). Now, right now, at the moment, Look!, Listen! = present continuous. Learners choose by cue before they choose by feel (Cue Sort).
2. **Choose in a sentence** with a one-line scene (Scene Check), then the same job in **silly scenes** (Funny Reporter): humour makes the contrast memorable, and the cue is still what decides.
3. **Spelling slips** that cost marks, on their own: -s / -es / -ies and -ing (drop e, double the last letter).
4. **State-verb trap:** know, like, want, love, need, understand, hate, have are not used with -ing (No -ing Club).
5. **Typed recall with spaced review:** Leitner Memory Vault, one card per sentence (`eg.alwaysNow.vault.v1`, this device only).

## Voice
Every cue word and every answered sentence is a pre-baked static clip (teacher voice). A test fails if a spoken line has no clip on disk. No browser voice, no live voice, no AI.

## Not covered
Adverb position, questions and negatives (do / does / is / are), "always" + continuous for annoying habits, future use of the present continuous.
