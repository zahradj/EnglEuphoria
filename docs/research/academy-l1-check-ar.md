# Arabic (ar) source check of the L1 watch list

Date: 2026-10-17. File checked: `src/curriculum/academy/l1Watch.ts` (104 entries whose langs include `ar`). Academy hub only.

## Method note

- Sources reached with the WebSearch tool (abstracts and result summaries). I opened in full only Wikipedia "Arabic phonology" (via curl). The MDPI page returned an error to curl, so its claims come from the search summary only.
- Nearly all journal items are known only from abstracts/snippets, not read in full; samples are small and mostly Saudi, Iraqi, Jordanian, Egyptian, Sudanese writing or error-analysis studies. Several come from low-tier journals. "supported" means an abstract says so, not that I verified the data.
- Not opened: Swan & Smith "Learner English" (no claim made), any paywalled paper. No search found anything for most 'K' items (modal + to, -ing, irregular verbs, register, rhetoric); "no source found" is a result of this search, not proof the pattern is false.
- Where a URL is a catalogue record only (e.g. the ADJ link), it is marked so.
- Verdict counts: supported 8, partly 15, no source found 81 (total 104).

## Entries to fix or drop

1. **A1-S07 (l.58) "adds a vowel after a final consonant": drop `ar`.** Arabic allows final consonants; the clustering problem for Arabic is mainly word-initial. No source for ar.
2. **A1-S02 (l.33) wording**: "case ending" describes Turkish, not Arabic. Rewrite for ar.
3. **A2-S01 (l.85) "still leaves out the past of be" (V)**: Arabic has an overt past copula (kāna), so this is not a clean transfer error, though omission in past is reported in Saudi writing. Keep as a watch with softer wording.
4. **A1-S02 (l.32), A2-S06 (l.111), A2-S12 (l.142), B1-S17 (l.238) extra-vowel entries**: epenthesis is reported for initial clusters, but one Levant Arabic study found none; final clusters (mustn't, fifth, -selves) have no source. Mark "may hear", keep V-weak or lower to K.
5. **A1-S12 (l.80)**: "uses the for everything" is too strong; documented overuse is mainly generic reference ("the life"); omission is also common.
6. **C1-S09 (l.358) and C1-S14 (l.377)** (politeness norms, rhetorical habits): no source found; stay hedged ("contested") and do not present as fact for ar.
7. **Evidence upgrades if the owner wants them**: l.156 (present perfect), l.187 and l.257 (passive), l.192 (resumptive) are supported by abstracts, so K/V-weak -> V is defensible; the resumptive item has only one teaching-experience source plus theory (RC4).
