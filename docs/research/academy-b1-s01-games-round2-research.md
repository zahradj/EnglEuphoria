## Shortlist: several games per lesson, each tied to a success criterion
One reusable scene kind serves several lessons with different data (and different looks, per the "vary the design of a repeated game" rule).

## Proposed build order
1. **Wave 1 (covers every lesson):** `inspect` (three looks), `interview`, `objection`, `cipher`.
2. **Wave 2:** `finder`, `workshop`, `switchboard`, `beats`.
Each new game needs: a lesson-plan amendment approved by the owner, content items, an aesthetic pass and screenshots, tests, recorded lines, and the art review for any new pictures.

## Own design choices (not from a source)
No-penalty feedback with an explanation, three-slot confirmation inside the interview, the three-day shift in the passport desk, the spoken summary step, and using one scene kind with several data sets and looks.
