# Research: how to sequence an Academy lesson (PPP, TTT, TBL, ARC, ESA, gradual release), 2026-10-13

Owner request (2026-10-13): "the sequencing of the lesson plan should be studied and searched on the internet, for example the PPP method: present, practise (controlled and free), produce. Search for other methods too."
Method: four web searches (standard mode). The sources are mostly teacher-education pages, reviews and position pieces, **not controlled studies**; none compared the frameworks on learner outcomes for one-to-one teens. Harmer's ESA, Pearson and Gallagher's gradual release and guided-discovery lessons for beginners did not come back as primary sources, so those rows are from general ELT knowledge and are marked [U].

## The frameworks
| Framework | Sequence | Strength | Weakness (from the sources) | Source |
|---|---|---|---|---|
| **PPP** | Present (context, meaning, form, sound) → controlled practice → freer practice → production | Easy to plan and run; clear for beginners; good for exam-style accuracy; elements are still in coursebooks | Assumes learning is linear; "free" practice may not make learners use the target form; teacher-centred | [TKT guide](https://open-exam-prep.com/study-guides/tkt-module1/background-to-language-teaching/teaching-frameworks), [critical review](https://journal.su.edu.ly/index.php/abhat/article/view/728), [PPP page](https://jobs.languagelink.ru/tefl_clinic/teaching_knowledge/teaching_methodologies/ppp.php) |
| **TTT** (test-teach-test) | Task first → teach only what the learner could not do → similar task again | No time wasted on known language; learner needs drive the teaching | Language focus can be unpredictable | [Cambridge, PPP vs TBL](https://www.cambridgeenglish.org/Images/759969-ppp-vs-tbl-page.pdf) |
| **TBL** (Willis) | Pre-task → task cycle (task, plan, report) → language focus | Authentic communication; focus on form comes from real use | Hard for true beginners (less teacher modelling); one study found less learner output than PPP | [Willis summary](https://www2.vobs.at/Ludescher/Grammar/task_based_learning.htm), [Cambridge](https://www.cambridgeenglish.org/Images/759969-ppp-vs-tbl-page.pdf) |
| **ARC** (Scrivener) | Authentic use (meaning, fluency) / Restricted use (form, accuracy) / Clarification and focus (explain), in any order | A checklist, not a rigid order; a balanced lesson has all three | Gives no fixed order | [TeachingEnglish ARC](https://www.teachingenglish.org.uk/professional-development/teachers/teaching-knowledge-database/c/arc), [Sanako](https://sanako.com/why-is-the-arc-lesson-structure-so-powerful-for-language-teaching) |
| **Guided discovery** [U] | Examples → learner notices the pattern → rule confirmed → practice | Noticing builds understanding; fits teens who can reason | Slower; needs a clear set of examples; hard for pure beginners | search found nothing specific |
| **Gradual release** (I do / we do / you do) [U] | Teacher models → together → learner alone | Lowers anxiety; the owner's "modelling" rule | Not language-specific | search found no language-teaching source |
| **ESA** (Harmer) [U] | Engage → Study → Activate | Simple, flexible | Not retrieved from a primary source | none |

Common point: the sources describe the same four elements in different orders: **C** meet the language (a text or model), **B** analyse form and meaning, **D** controlled practice, **A** do a task. PPP runs C-B-D-A; TBL runs A-C-B-D ([language-teaching comparison]( https://www.cambridgeenglish.org/Images/759969-ppp-vs-tbl-page.pdf)).

## Decision for the Academy (the order of every lesson, by who is in the seat)
The learners are A1 teens in one-to-one lessons, so a **modelled, explicit** order (PPP with gradual release) is the default for **teaching** episodes, with a task at the end to answer PPP's weak "free" stage. TBL or TTT order is used where the learner already has the language (E4, E6, E8). Every lesson also checks the ARC balance (some Authentic use, some Restricted use, some Clarification).

| Stage (field `stage` on a slide) | What it is | Gradual release | ARC |
|---|---|---|---|
| `context` | Story or situation that gives the language a reason (The Drop) | I watch | A |
| `model` | The teacher (or cast) says it, twice, with pictures | **I do** | C |
| `rule` | The rule stated in at most 3 lines, with examples; the student repeats it | I do | C |
| `controlled` | Games with one right answer and immediate feedback (match, memory, hear-and-pick, build) | **We do** | R |
| `free` | Open practice with choice (This or That, pick a badge) | We do → you do | A |
| `produce` | The Mission Take 1, feedback, Take 2, then the Release | **You do** | A |
| `review` | Retrieval of earlier lessons (Remember?) and teach-back at the Wrap | you do | R |

**Order law (checked by a test):** for each language point, `model` comes before `rule`, `rule` before `controlled`, `controlled` before `free`, `free` before `produce`. The teacher feedback after Take 1 (`fade`) is the language-focus step (Willis); the Release is the "test" of a TTT.

## By episode type
| Episode | Order | Why |
|---|---|---|
| E1 Cold Open | context → model → rule (short) → controlled → free → produce (small) | New topic, beginners: model and state the rule first |
| E2 Word Lab | context picture → model words → controlled (two games per set) → free describe-and-guess | Vocabulary: PPP with the two-games rule |
| E3 Pattern Lab | **TTT / guided discovery**: Test 1 (describe a photo with E1-E2 words) → noticing examples → rule → controlled → Test 2 | The learner already has the words; teach only the gap |
| E4 On Air | model dialogue → controlled phrase ladder → **task first-ish**: role-play → feedback → Take 2 | Interaction practice |
| E5 Deep Dive | pre-read (predict) → read → language focus (collocations) → summarise | Reading skills lesson |
| E6 Side Quest | TBL: pre-task → task of the student's choice → report → language focus | Student autonomy |
| E7 Remix | retrieval first, then a boss task | No new language |
| E8 Finale | TBL: task (Take 1) → feedback → Take 2 → Release | Season Release |

## Limits
- Evidence is thin: reviews and teacher-education pages, no controlled one-to-one study, no source on guided discovery for beginners, and one study (PPP vs TBL) found less learner output in TBL. This sequence is a reasoned design to be tested with real learners, not a proven method.
