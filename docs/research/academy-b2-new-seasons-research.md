## B2-S17 Mind Matters (stress, sleep, screens, supporting a friend)

Structures: purpose clauses (so that, in order (not) to, so as not to) as Pattern Lab; had better / ought to as Side Quest.

Level evidence (open CEFR-J Grammar Profile CSV, rows 95, 160, 126, 137): `in order to DO` CEFR-J B2.2, EGP B2; `ADVERBIAL CLAUSE: so that` CEFR-J B2.1, EGP B1; `had better` EGP B2, no CEFR-J level; `ought to` EGP B1-B2, GSE B1. The A2 plain infinitive of purpose (`infinitive-purpose`) is a different, earlier form, so `purpose-clauses` is a clearly different structure. `had-better-ought-to` is marked unverified (one profile column only).

## B2-S18 Study Abroad Plan (course, application, exchange year, motivation)

Structure: preposition + -ing (look forward to, be/get used to, instead of, apart from, interested in, not + -ing).

Level evidence (CEFR-J CSV rows 105-115): `PREP+V-ING` CEFR-J A1.3, EGP A2, i.e. basic "before -ing" is early, but `not + V-ING` CEFR-J B2.1 and possessive + -ing (EGP B2). The fixed set with *to* as a preposition (look forward to, be used to) is a classic upper-intermediate learner error. Searching for the English Grammar Profile did not return the profile page itself, so the level for the fixed set is the team's judgement: marked unverified.
