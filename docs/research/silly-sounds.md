# Silly Sounds Circus (Academy game) — design note

Owner request (2026-10-13): a funny phonics game.

## Audience and aim
Academy teens read English well and pronounce / spell by sound poorly. English spelling hides the sound (through = blue, though = go, rough = stuff). The game trains the ear on the patterns that surprise readers, in a funny circus setting.

## Stops
1. **Rhyme Roulette** (ears): hear a word, pick the rhyme whatever the spelling (ough, igh, eigh, ear, oo).
2. **Odd One Out** (ears): four words, one different vowel sound.
3. **Silent Ninja** (spelling by sound): tap the letter nobody says (kn, wr, mb, silent t / s / h / d).
4. **Spelling Doctor** (spelling): silly sentences with three spellings; the tip names the pattern.
5. **Parrot Echo** (say it): record yourself next to the model, tick two self-check boxes. Private, never scored, never uploaded.

## Voice
Every word and sentence is a pre-baked static clip (teacher voice). A test fails if a spoken line has no clip on disk, and another that no heteronym (read, lead, wind, live, tear, bow, row...) is ever spoken. No browser voice, no live voice, no AI, no speech recognition.

## Not covered
Stress and intonation, -ed endings (t / d / id), consonant clusters (see Sound Lab and Twister Lab).
