# Academy: matching and memory games for vocabulary — candidate list (2026-10-12)

Owner request: search the internet for different matching games that improve student memory and prepare a list.
Use with the vocabulary rule (two different memorising games after every vocabulary introduction, `docs/academy-lesson-system.md` §2.1c).

## Sources and honest limits
- Web search 2026-10-12. Memory/concentration variations: [Games to Learn English: Concentration](https://www.gamestolearnenglish.com/concentration/), [ESOL Courses memory games](https://www.esolcourses.com/vocabulary/memory-games.html), [ESL Activity: top 5 memory games](https://www.eslactivity.org/top-5-esl-memory-games/), [The ESL Teacher Life: matching games](https://theeslteacherlife.com/matching-games-for-esl/), [TEFL Institute: ESL games](https://teflinstitute.com/blog/7-essential-esl-games-list-for-effective-classroom-teaching/). Wordwall template families: [Wordwall features](https://wordwall.net/features) (confirms Match, Quiz, Crossword, Maze Chase, Airplane; the page did not list the other templates I searched for).
- Evidence: spaced retrieval beats restudy for foreign vocabulary in the lab studies found (e.g. a Swahili-English study, UTA thesis), but only when learners already have enough prior repetitions to succeed, and the retrieval advantage depends on task design (Educational Psychology Review, 2023 experiments). More active recall is better than recognition [secondary summary]. A 2026 Kahoot! blog claims big gains from game-based vocabulary study — vendor source, treated as promotional. **No source found compares matching games with recall games directly.** Consequence: a matching game is a good FIRST step (recognition, safe, success-first); it must be followed later by production (say it, type it) — which the Remember? part and the Mission already do.
- Items marked [general] come from the repo catalogue (`docs/academy-games-catalog.md`) or general teaching practice, not from this search.

## The list (A = already in the player, N = new to build)

| # | Game | How it works (comfort-first, no timer, no ranking) | Trains | Status |
|---|---|---|---|---|
| 1 | Drag-match (picture ↔ word) | drag the word onto the scattered picture | meaning | A (`match`) |
| 2 | Listen-and-pick | hear the word, tap its picture | sound → meaning | A (`match` listen) |
| 3 | Flip memory (picture ↔ word) | flip two cards, hear the word | meaning + place memory | A (`memory`) |
| 4 | Flip memory, sound pairs | match words that share a sound (cat–hat) [ESOL Courses, Concentration] | phonics | N |
| 5 | Sentence halves | flip/drag two halves to rebuild a sentence [ESL Teacher Life] | grammar + vocab | N |
| 6 | Word ↔ meaning ↔ example (triples) | find THREE linked cards: word, picture, example sentence [irregular-verb triple variant, ESOL Courses] | depth of knowledge | N |
| 7 | Category sort | drop items into labelled baskets (feelings, countries, classroom words) [ESL Teacher Life] | grouping, recall by category | N |
| 8 | Shadow match | match a picture to its silhouette | visual discrimination | A (`shadow`, sticker pictures only) |
| 9 | Odd one out | tap the word that does not belong and say why [catalogue #3] | categories | N (catalogue) |
| 10 | Kim's game (what is missing?) | look at 6 pictures, cover, one disappears; say or pick which [general] | short-term memory, recall | N |
| 11 | Snap / spot the match | two pictures change slowly; tap when picture and word agree, calm speed [general] | recognition speed (optional, no timer pressure) | N |
| 12 | First-letter match | picture ↔ its first letter for beginners [ESOL Courses] | letter-sound | N |
| 13 | Spelling rebuild | drag letter tiles to build the word under its picture [general] | spelling | A (`spell`) |
| 14 | Missing-word cloze | tap the word that fits a sentence gap [Wordwall-style] | use in context | N |
| 15 | Hidden-object hunt | find the words in a scene [catalogue] | meaning in context | A (`hunt`, homework) |
| 16 | Pelmanism with a twist: "memory then say" | after a pair is found the student says the word (private record, optional) | production | N |
| 17 | Word-wall recall (Memory Palace) | walk through last lesson's scene; tap objects to name them [catalogue #100] | spaced retrieval | N (catalogue) |
| 18 | Tile-matching review | clear word and meaning tiles, calm, no timer [catalogue #98] | review | N (catalogue) |
| 19 | Connections | group 16 words into 4 hidden groups [catalogue] | categories, B1+ | N (catalogue) |
| 20 | Dictation match | hear a sentence, drag the words in order [general] | listening + spelling | A (`build`) |

## Suggested next picks (cheap to build, high value)
1. **Category sort (7)** — new mechanic, very different from the two games we use; works for every word set.
2. **Kim's game (10)** — a different memory skill (recall without cues) and good for the Energiser.
3. **Triples (6)** — deeper than pairs: word + picture + example.
4. **Sound pairs (4)** — links to the pronunciation focus of each Season.

Rule of thumb for the two games after a word set: first game = recognition (1, 2, 3), second game = a different kind (7, 10, 6, 14) so memory is trained two ways.
