# Academy — expert English-teaching research round (2026-10-16)

Why: the owner asked (before the next merge) for an expert-level pass on English-learning and English-teaching knowledge. Companion to `docs/academy-learning-science.md` and `docs/research/academy-curriculum-teen-sla-and-l1-gaps.md` (read first; their findings are not repeated). This round **confirms, corrects and adds**; it does not replace them.

Method: web search, 2026-10-16, two rounds (17 queries). The search tool returns summaries, not full papers, so nothing was read in full. Mechanics, structure and principles only; **no content is copied**.

Marks: **[V]** a result seen this session (summary level) · **[V-weak]** seen only in blogs, small studies or theses · **[K]** known from memory, not re-checked · **[U]** unverified. Every number must be checked in the original paper before any parent-facing or public use.

## 2. What this changes (decisions, with the check that enforces them)

1. **Four-strands audit per lesson** (new, add to the skill's done-checklist): count the lesson's minutes in input / output / language-focused / fluency. Target a spread of all four, not one; for B1-S01-E1 the language-focused share is large (rule + forge), so the fluency strand must be real: a **repeated** speaking task with no new language (Take 2, the Release).
2. **Task repetition is now named as evidence**, not habit: Take 2 must change one thing (new listener/NPC, tighter time, or different topic) so that it is a true repetition, not a retry of an error.
3. **Feedback ladder stays** (nudge → clue → direct), now with Li and Lyster & Saito as sources; delayed correction during fluency tasks stays. No effect sizes quoted.
4. **Spacing**: keep 1-2-4-8-16, but state that the exact expansion is not critical; the lesson that matters is **total spaced retrievals** and that adults benefit from longer gaps. Production first in review (fill-in / say it), recognition second.
5. **Vocabulary tasks need need + search + evaluation**: a word kept from reading should be *used* in a sentence by the student the same lesson, not only matched. B1-S01-E1's six words each need one "use it about yourself" slide; check this list when the pictures return.
6. **Listening**: any listening check follows predict → listen → compare → listen again → reflect; check `listening-check` slides have a "what do you think you'll hear?" step or add it.
7. **Coverage**: keep the 95/98 % known-word rule as a design target but stop calling it a requirement in any parent-facing text (gate check 12).
8. **Pronunciation**: the Mission and Release are judged on **being understood**; the recording feedback names one high-impact error at a time, never "accent".
9. **Games**: games with a story and a teacher-led wrap-up (our Mission/Release, Verb Draw's chat recap) are the better-supported kind; keep a short teacher debrief after every game block.
10. **L1 notes for the present perfect lesson** (add to the teacher note): Turkish/Arabic → past simple instead of present perfect; Italian/Spanish/French → present perfect with *yesterday/last year* and *da/desde/depuis* for "for/since"; show the **time-word rule** early ("if you say when, use the past simple").
11. **Limits stated**: our design is not proven by a trial; nothing here promises a CEFR level in a number of weeks.
