# Academy lesson system — "Seasons" (one-on-one, 60 min, ages 11–18, A1 → C1)

Status: **proposal for owner approval** (2026-10-08). Nothing here is built yet. It extends `docs/research/academy-lesson-design.md` (evidence base), `docs/academy-learning-science.md` (**the scientific techniques, how each is built in, and how we measure acquisition**) and `docs/research/academy-teen-games.md` (teen game rules).
Evidence labels: **[V]** seen in a source this session · **[K]** established literature/knowledge, re-check before quoting · **[RT]** rule of thumb · **[U]** unverified. Web fetching was mostly blocked, so many items are from search summaries.

**Design brief (from the owner):** lessons are **one-on-one, live, 60 minutes**; the **student's comfort is the top priority**; units are **themed**; lessons are **fun**; the student must **actually acquire English** and **feel** their progress; the player layout must suit teen taste.

---

## 1. The idea in one page

> **Every unit is a *Season*. Every lesson is an *Episode*. Every 60 minutes is a *Live Session* in which the student is the lead, not the audience.**

Four things make it ours (and four are borrowed from evidence, not invented):

1. **A themed story world per Season** (cast: Vee, Ava, Theo, Mia). One *clue* per episode is unlocked only by *using* the target language ("language is the key", like the existing `expedition_game`). The Finale solves the story with the student's own language.
2. **"My World" skins.** The language spine of an episode is fixed; the *topic skin* (football, gaming, music, anime, art, tech, animals, food, travel…) is chosen by the student. Personalisation and choice raise motivation and learning (Cordova & Lepper 1996) [K].
3. **Make-something Seasons.** Every Season ends with a *Release*: something the student **makes in English** and keeps (profile card + voice intro, recorded vlog script, café menu + order role-play, podcast episode, comic…). All Releases build a private **portfolio**: the "before/after" evidence of real acquisition.
4. **The student is the expert.** One segment per session flips roles: the teacher plays a clueless friend/alien/new classmate and the *student* explains, corrects the teacher's planted mistakes, or runs the game (protégé/teaching effect [K]).

Borrowed from evidence: noticing before rules; retrieval and spacing between sessions; choice (autonomy); low-stakes private speaking (see the evidence doc).

**Honest status.** The Season System is an *original synthesis*; no study tests it as a whole. Pilot with 5–10 learners and judge it with the measures in §9 before scaling.

## 2. Progression pattern (the same shape at every level)

### 2.1 Season = 8 Live Sessions

| Ep | Name | Purpose | Main skill | New language? |
|---|---|---|---|---|
| E1 | **Cold Open** | Hook + context text/dialogue; gist only | Listening / Reading (receptive) | Seen, not produced |
| E2 | **Word Lab** | The Season's words (≤ 14) + sounds/stress | Vocabulary, Pronunciation | Yes — words |
| E3 | **Pattern Lab** | Notice → pattern → ≤ 3-line rule → controlled use | Grammar | Yes — 1 structure |
| E4 | **On Air** | Real-life exchange built from E2+E3 (functional language) | Speaking / Listening | Chunks only |
| E5 | **Deep Dive** | Longer graded text/clip + a short written piece with rewrite | Reading / Writing | Few |
| E6 | **Side Quest** | Student's pick: fluency, creative or cultural task; second structure (if any) | Integrated, high choice | Light |
| E7 | **Remix** | Consolidation + boss round mixing this Season with earlier ones | All (retrieval) | **None** |
| E8 | **Finale** | Peer task (≥ 1 unscripted turn) + Release + mixed checkpoint | Speaking / Writing | **None** |

Rules: new vocabulary in E2 and E6 only; new structure in E3 and E6 only; E7–E8 are **zero new language**. Every 2nd Season, E7 is a **Big Remix** (cumulative, covers two Seasons). Matches coursebook practice: a productive end-of-unit task and a cumulative review every 2 units [V: Solutions, Roadmap].

### 2.2 Spiral across Seasons

- **Recycle:** each Season's E1 re-uses ~30 % of words from the previous two Seasons, so every target word meets ≥ 8–10 varied encounters across skills [K/RT]. 20–30 % new language per lesson [RT, from research].
- **Mix for retrieval, not for learning new words:** E7 and the *Daily 10* (§6) mix everything that is due (spacing + retrieval). New vocabulary is learned in blocks (interleaving worked *against* word learning, g = −0.39 [V]); only confusable grammar contrasts are interleaved, after each is learned alone. See `academy-learning-science.md` §2–3.
- **Dial down the supports ("training wheels").** Support fades by level and the student *sees* it:

| Support | A1 | A2 | B1 | B2 |
|---|---|---|---|---|
| First-language hint button | on | on, tiered | on request | off (dictionary only) |
| Sentence starters | full frames | half frames | first words | none (optional) |
| Audio speed | 0.8× available | 0.9× | natural | natural + accents |
| Speaking ladder ceiling | repeat → substitute → answer → ask | exchange → extend | spontaneous 2 min | spontaneous 3–5 min + opinion defence |
| Teacher talk time target | ≤ 40 % | ≤ 35 % | ≤ 30 % | ≤ 25 % |
| Method in the Mission | notice → practise → produce | notice → practise → task | task → focus on form → repeat task | task-led; mediation (summarise/relay) |

The student's **Training-Wheels meter** (hints used per session trending down) is an honest progress signal.

**C1 shape adjustments** (same 8 episodes, different weight): supports all off by default; E3 *Pattern Lab* becomes **Language Lab** (notice register, collocation and stance in an authentic text); E4 *On Air* becomes a seminar / pitch / interview; E5 *Deep Dive* uses long authentic texts and a 250–300-word piece with feedback on **precision and register**; every Season has **mediation** work (summarise, relay, mediate viewpoints) and ≥ 1 extensive-reading/listening target for the Daily 10. This also addresses the B2 "plateau" (suggested remedies: extensive reading just below level, collocation/chunk noticing, feedback on precision [V, weak sources]).

## 3. The 60-minute Live Session ("run of show")

Fixed order so the student always knows where they are; the *mechanics* inside change every session (Variety Rule: ≤ 2 same-kind in a row; ≥ 12 distinct mechanics per Season; ≥ 1 new or upgraded mechanic per Season).

| Min | Segment | What happens | Comfort / fun lever |
|---|---|---|---|
| 0–5 | **Check-in** | Energy dial (😴 → 🔥) + 3 "quick-fire" questions from the student's world. Teacher adapts the plan from the dial. | Soft landing; spontaneous speaking with zero stakes |
| 5–12 | **Remember?** | Retrieval of last session + whatever the Daily 10 flagged "fading". Production first (type/say), recognition second. Retention score vs the student's own past. | Competing only against yourself; mistakes go to the Mistake Bank, not shame |
| 12–22 | **The Drop** | New input: story beat, clip, voice message from a cast member, mystery clue. Tappable words, gist check. Student picks 1 of 2 topic skins. | Surprise (variable reward) + autonomy |
| 22–32 | **Notice & Build** | Vocab or pattern discovery with the teacher (Socratic), ≤ 3-line rule, 2 different controlled-practice mechanics | Choice of mechanic (2 offered) |
| 32–36 | **Energiser** | 4-min break-the-pattern game (Wordle-style, Would-you-rather, charades, lightning round, music) | Attention reset; pure fun, no scoring pressure |
| 36–48 | **Mission** | The communicative task (info-gap, decision, role-play, story, debate). **Take 1** → teacher feedback by *prompt* (not bare recast) → **Take 2** (same task, new angle or shorter limit) | **Difficulty dial: Chill / Normal / Push** — student chooses; "Need a minute" always available |
| 48–55 | **Release** | The student makes this Season's piece (private recording or text first → listen/read back → send or retry) and files it in the portfolio | Ownership; private-before-public |
| 55–60 | **Wrap** | "I can…" tick-offs, Mistake Bank "fixed" count, **Best Line of the Session** (the student's own best sentence, saved), pick next session's skin, 1-tap enjoyment emoji | End on a win |

**Core vs flex.** *Core (45 min, never skipped):* Remember?, Drop, Notice & Build, Mission, Release, Wrap. *Flex (15 min, teacher's call):* Check-in, Energiser, Take 2, extra practice. If the student is tired (dial 😴) the teacher swaps the Mission for the **Chill track** (lower-pressure game, same target language) — no student ever "fails" a session.

**Fun ingredients (use ≥ 5 per session):** surprise Drop · student-chosen skin · story clue · teacher-as-clueless-friend flip · a make-something Release · humour (absurd scenarios, "weird but true") · a boss moment (Remix/Finale) · collectable *Word Cards* (private deck, teen idiom — **not** stickers/mascots, per the Academy prompt ban) · music/Song Take · live reactions/emoji · a running in-joke across the Season.

## 4. Roadmap A1 → B2 (sizing and sequence)

### 4.1 Sizing (data-informed; verify before publishing)

| Level | Cumulative guided hours (Cambridge) | Cumulative words (target) | Seasons | Live sessions (60 min) | New words/Season |
|---|---|---|---|---|---|
| A1 | ~90–100 [K] | 600–800 | 10 | 80 | 60–80 |
| A2 | 180–200 [V] | ~1,500 | 12 | 96 | ~67 |
| B1 | 350–400 [V] | ~2,700 | 16 | 128 | ~75 |
| B2 | 500–600 [V] | ~4,000 | 16 | 128 | ~80 |
| C1 | 700–800 [V] | ~5,500 (Oxford 5000 adds ~2,000 B2/C1 words to the 3000 [V]; C1 ≈ 5–6k word families, provisional [V]) | 16 | 128 | ~90 items (words + collocations) |
| **Total** | | | **64** | **560** | |

- **Reconciling with the hours data.** Cambridge's cumulative guided hours imply roughly 95 / 95 / 180 / 175 new 60-min lessons per level (≈ 545 to B2) [V for the hours]. This plan schedules **432 live sessions** and relies on ~120 h of *Daily 10* self-practice to close the gap. That trade is an **assumption**: one-to-one gives far more speaking per hour, but there is no hard data on how many fewer hours it needs, so do not cut the budget silently. **Alternative if the owner prefers to follow the hours strictly** (C1 adds ~200 hours, 700–800 cumulative [V]): A1 12, A2 12, B1 22, B2 22, C1 25 Seasons (≈ 744 sessions); the Season shape does not change.
- Guided hours are class hours, not guarantees, and depend on age, intensity, background and out-of-class study (Cambridge).
- Pace (sessions per week varies by family: 1, 2 or 3): A1→C1 (560 sessions) takes ≈ 10.8 / 5.4 / 3.6 years in a 52-week year (add ~10 % for holidays); A1→B2 (432) ≈ 8.3 / 4.2 / 2.8. **Tell families this honestly.** Reaching C1 inside the teen years needs ≥ 2 sessions a week from about age 12, or a start higher up the roadmap after placement. The teacher dashboard shows each student's own estimated finish date.
- Vocabulary supports: ~2–3k word families give ~95 % coverage of spoken text; 98 % needs 6–7k spoken / 8–9k written families (Nation 2006, van Zeeland & Schmitt) [V]. B2 ≈ 4k words is *enough to follow most speech*, not enough for academic reading — say so.
- Per Season: 1–2 structures, ≤ 14 new words per session (hub cap), 8 sessions; roughly 60 % of new words productive, the rest receptive. Recheck counts against the Oxford 3000/5000 and Cambridge English Vocabulary Profile lists before locking [K].

### 4.2 Grammar sequence by level (from the English Grammar Profile pattern; **verify against EGP** [K])

- **A1:** be · have got · there is/are · present simple (+ questions, negatives) · can/can't · imperatives · possessives · this/that/these/those · countable/uncountable, some/any · prepositions of place/time · present continuous (now) · like + -ing · wh-questions · adverbs of frequency.
- **A2:** past simple (regular → irregular) · past continuous · comparatives/superlatives · going to / will · present perfect (experience, ever/never) · have to / must / should · quantifiers, too/enough · adverbs of manner · infinitive of purpose · first conditional (intro).
- **B1:** present perfect vs past simple · present perfect continuous · past perfect · used to · zero/first/second conditionals · passive (present/past) · reported statements · defining relative clauses · modals of deduction · linking words · phrasal verbs · future forms.
- **C1** (advanced structures agreed across teaching sources [V]; full list from the English Grammar Profile still to verify [U]): inversion after negative/restrictive adverbials and inverted conditionals · cleft sentences and fronting · mixed conditionals and the subjunctive · advanced participle/reduced clauses · ellipsis and substitution · nominalisation and complex noun phrases · passives with reporting verbs · modal nuance (*needn't have*) · hedging, stance adverbials, discourse markers · concession (*be that as it may*) · register control and collocation precision. About 2 per Season (~32 total), introduced early and recycled, not taught all at once; use inversion sparingly in writing.
- **B2:** third and mixed conditionals · passive range · reported questions/commands · non-defining relatives · future perfect/continuous · wish/if only · perfect modals · participle clauses · hedging and discourse markers · formal/informal register.

Sequencing follows learnability, not just frequency (order-of-acquisition and Processability Theory research) [K]: teach what the learner can process, re-visit forms (e.g. 3rd-person -s) in spiral recycling because they stay error-prone.

## 5. Games and activities in the lesson pattern

The full catalogue (≥ 120 entries with skill, level, one-to-one adaptation and comfort rating) is `docs/academy-games-catalog.md`. **Rules for choosing from it:**

1. Pick by *what the learner must retrieve*, then by teen appeal.
2. One-to-one adaptations: teacher vs student, **student vs own best**, **teacher + student vs the game**, student-as-expert, or teacher plays the "clueless friend".
3. **Comfort rating** on every game: Low-stakes (default for Chill track and Check-in), Medium, Higher-pressure (only in Mission "Push" or Remix/Finale boss, only if the student opts in).
4. **Avoid:** public leaderboards, elimination, forced speaking/camera, visible countdowns as default.

**Segment × episode map** (families; pick one per segment from the catalogue, never the same twice in a row):

| Segment | E1 Cold Open | E2 Word Lab | E3 Pattern Lab | E4 On Air | E5 Deep Dive | E6 Side Quest | E7 Remix | E8 Finale |
|---|---|---|---|---|---|---|---|---|
| **Remember?** | recall words from last Season | recall E1 story words | recall E2 words (type) | recall E3 pattern | recall E4 phrases | recall Season so far | cross-Season SRS | Season recap quiz vs own best |
| **Drop** | mystery message / clue | picture-word reveal | spot-the-pattern text | audio dialogue | graded text or clip | student-chosen skin text | boss briefing | finale briefing |
| **Notice & Build** | gist + true/false | match/type/dictation | find-the-pattern + builder | phrase-ladder | cloze + reading detective | free choice (2 offered) | mixed retrieval grid | checkpoint warm-up |
| **Energiser** | Would-you-rather | Wordle-style | fix-the-chat | charades/guess-who | 20 questions | student's pick | rapid-fire | song / quiz |
| **Mission** | predict & share | describe-and-draw / info-gap | sentence-build duel | role-play / decision task | summarise & debate | creative project | boss round (opt-in) | peer-style task (take 1 + take 2) |
| **Release** | 1-sentence opinion | voice-note: my words | written sentences | recorded dialogue | short text + rewrite | mini creation | recap clip | the Season Release |

**Per-skill mechanics** to draw on (details in the catalogue): Vocabulary (type-the-word, spaced queue, Wordle-style, odd-one-out) · Grammar (fix-the-group-chat, tile builders, notice-the-pattern, expedition-style choose-then-justify) · Reading (branching story, detective reading, tap-gloss reader) · Listening (dictation, audio clue chains, spot-the-difference audio) · Speaking (voice-note tasks, collaborative decision, mini-debate, role-play, 2 truths & a lie, hot seat) · Writing (message/caption with rewrite, comic captions, review) · Pronunciation (shadowing, minimal-pair duels, stress-pattern tap).

**Voice rule (repo hard rule):** every spoken clip in listening, dictation, pronunciation or the Drop uses `speak()` with the approved recorded voices — never browser TTS.

## 6. Between sessions: the Daily 10

Acquisition needs spacing; one live hour a week is not enough alone [K]. The existing solo player and `srs.ts`/MemoryBank become a **10-minute daily set**: due items first (≈ same session → +1 → +3 → +7 → +21 → +60 days, a miss drops back to +1 [RT]), then 2–3 mixed mini-games, then one 30-s voice note. Optional, forgiving: daily goal separate from the streak, freezes, team/teacher-visible only (Duolingo's own tests: separating goal from streak helped retention [V, relative]).

## 8. Player layout and comfort (research-backed)

**Layout (laptop):** top bar 48–56 px (title, *stories-style segment strip* for the 8 run-of-show segments, quiet elapsed clock; no countdown) · **stage ≈ 72–75 %** (one task at a time) · right rail 280–360 px with teacher video on top, hideable self-view, chat/reactions · bottom dock 64–72 px with comfort controls · teacher-only drawer for plan/notes. **Phone:** portrait = sticky teacher video (≈ 25–30 % height, collapsible/PiP) + stage + thumb-zone dock (≥ 48 px, safe-area aware); landscape = stage 65 % + slim rail. Audio before video if bandwidth drops. Cambly/Preply/italki all use one big shared canvas + video tile/rail [V].

**Style:** dark-first with light option; one accent + one reward colour; 12–16 px rounded cards; big type (Lexend or Atkinson Hyperlegible; benefits of "dyslexia fonts" are weakly evidenced, don't claim them [V]). Two **theme token sets** on one layout: **Explorer (11–13)** — more colour/illustration, 18–20 px body, labelled icons; **Studio (14–18)** — muted Spotify/Discord-like palette, 16–18 px, icon-first with tooltips, subtle XP. Learner can switch; no evidence supports a hard 13/14 split [U].

**12 rules:** one task on stage · labels next to their object · signal what matters · don't duplicate text+speech · teacher's face visible by default · touch targets ≥ 44 px (WCAG 2.2 floor is 24 px) · body ≥ 16 px (18 for A1–A2/11–13), 45–70 char lines, contrast ≥ 4.5:1 · respect reduced-motion/colour-scheme/safe-area, no flashing · no visible timers by default · every sound has a visual equivalent + mute · feedback wording "Not yet — try again", never red-X buzzers, never colour alone · no hover-only controls.

**Comfort dock (always visible to the student):** Hint (tiered: picture → first letter → answer) · Slow down / Repeat · **"I need a minute"** (pauses everything, tells the teacher, calm message) · **Private rehearsal** (record → listen → send/retry) · type-instead-of-speak · emoji reactions · camera off / self-view hidden / mute / blur · **Easier / Same / Harder** dial · choose the next activity from 2 · "I'm confused" and a private "I'd like to stop" · L1 hint toggle. **Teacher cues:** soft flag when "minute"/hint is used > 3×; talk-time ratio (`TalkTimeMeter` exists); 5–7 s wait-time prompt; "switch to Chill track" suggestion.

**Safety:** recording only with guardian consent and a visible indicator; chat limited to the lesson, logged, filtered; no public profiles or location; COPPA (<13, US) / GDPR-K (13–16 by country) / UK Age Appropriate Design Code to be reviewed with counsel [V for the Code, U for specifics].
